# teamogeo — Maket 3D SMAN 66 Jakarta

Model 3D interaktif hitam-putih dari **SMA Negeri 66 Jakarta**, dibuat sebagai referensi tata letak spasial untuk tugas peta makalah Geografi kelas 10.

**Link Web:** [teamogeo.vercel.app](https://teamogeo.vercel.app/)

## Fitur Utama
- **Kontrol Kamera 3D & Preset Sudut Pandang:** Bisa diputar bebas (*orbit*), *zoom*, atau langsung pilih sudut pandang isometrik, tampak atas (*top-down*), dan tampak bawah.
- **Tampilan Garis Kontras Tinggi:** Gaya maket hitam-putih dengan garis tepi yang jelas supaya mudah dibaca dan diolah ulang menggunakan AI maupun dijiplak untuk diagram peta.
- **Unduh PNG Sekali Klik:** Simpan tampilan layar langsung dalam format PNG untuk dimasukkan ke makalah, presentasi, atau dijadikan gambar referensi AI.

## Cara Pakai
1. Buka [teamogeo.vercel.app](https://teamogeo.vercel.app/).
2. Putar atau pilih sudut pandang kamera yang sesuai dengan kebutuhan peta kelompokmu.
3. Klik **Download PNG** untuk menyimpan gambar dasar, lalu lengkapi dengan data hasil survei lapangan masing-masing.

## Catatan
- Proporsi bangunan dan detail kecil bersifat pendekatan visual dan **tidak 100% akurat sesuai skala asli**.
- Dibuat hanya sebagai patokan tata letak awal—tetap gunakan data observasi lapangan kalian sendiri untuk isi petanya.
